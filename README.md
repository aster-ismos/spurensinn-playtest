# spurensinn-playtest
Depot for Spurensinn Playtest builds

## How to Play
* Click on Releases
* Choose appropriate Release (Round 1, 2, etc)
* Download .zip
* Extract .zip
* Start Spurensinn.exe
(If prompted, More info > Run Anyway)

# For Remote:
## How to Reduce Video File size
* Download the open source video transcoder Handbrake (https://handbrake.fr/)
* After installing, follow directions on the application
* Place the video into the application window as directed
* Choose one of the Fast 720p30 or 1080p30 presets
* Choose Save As destination
* Start Encode
* Share downsized file
